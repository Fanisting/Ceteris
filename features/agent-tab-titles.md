# Agent tab titles

Agent tabs get short, readable titles. Spinners and symbols that an agent puts in its own title are removed, and long titles are cut to a length you choose. The default is 24 characters.

You can go further. In Settings under AI Assistant, turn on Tab titles. After each turn, a model reads the end of the screen and writes a title by your rules. It keeps the old title while the task stays the same.

This is off by default, because the end of the screen is sent to the model. It uses the same service and model as [Next prompt suggestions](next-prompt-suggestions.md). It covers all built-in agents.

A title you type yourself is never overwritten.
