# Back to the last session

A small chip sits at the start of the sidebar tag bar, left of Running. It shows the session you were on before this one and its folder, for example `↶ claude · paper-draft`.

Click it to go back to that session, in any folder. Click it again to return. It switches between your last two sessions, like Alt+Tab. On the new terminal page it takes you to the last session you looked at.

The chip opens a session the same way a click on its sidebar row does. A session held by another window brings that window to the front. When the session is in a remote folder, the sidebar switches to the remote list.

Each window keeps its own history, in memory only. Closed sessions are skipped. When there is nowhere to go back to, the chip is hidden. There is no keyboard shortcut.
