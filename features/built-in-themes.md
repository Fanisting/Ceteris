# Built-in themes

Ceteris ships with more than 90 themes. Each one colours the whole window and the terminal together.

The default is Ceteris Dark, with Ceteris Light beside it. Others include Rose Pine, Catppuccin, Tokyo Night, Dracula, One Dark Pro, Ubuntu and Windows Terminal. Cute and soft themes include Cutie, Light Pink, Fairyfloss and Meizi.

Seven pearl themes use gem tones: Lapis, Sapphire, Rose Dew, Ember, Jade, Moonlight and Frost. Six themes come from LaTeX Beamer templates: Metropolis, Metropolis Dark, Madrid, CambridgeUS, AnnArbor and Spruce. They feel at home next to a paper.

To change the theme, open Settings and go to Appearance, then pick one from the theme menu. The change applies to all windows at once.
