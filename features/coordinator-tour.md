# Coordinator tour

The coordinator tour is a short animated guide over the real window. It starts the first time you launch a new or upgraded Ceteris, and when you set a Coordinator role.

It introduces the three roles, then shows with a spotlight and a cursor how to make a Coordinator, add a Worker, open Settings and install the plugin. It moves on as you act and lets every click through.

At the end it teaches you to turn another agent into a Fintuner. When that agent starts, Ceteris pastes a ready prompt for you. It pastes but never sends, so you decide. You can also paste a sample task into the Coordinator.

The tour speaks your interface language. If you do not use Claude Code, it skips the steps that only Claude Code needs.
