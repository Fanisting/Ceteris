# Custom themes

A theme can be a single CSS file. Put it in the themes folder inside the Ceteris data folder. It shows up in the Custom group of the theme menu.

When you save the file, every window updates at once, including the terminal colours. No restart is needed.

To start, open the theme menu and choose "New from current theme". Ceteris writes a commented template with your current colours and opens it in your default editor. A template file in the same folder lists every colour you can change and what it does.

The file can hold other CSS rules too. They apply only while that theme is selected. A theme file is easy to copy and share.
