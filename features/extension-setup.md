# Extension setup card

On the first start after you install or update Ceteris, one card lists the agent extensions and sets up the ones you tick.

## What it lists

Three groups, five items: for Claude Code, the ceteris-tabs plugin and formula images; for Codex, the ceteris-tabs server and formula rendering; for Ceteris, the Coordinator tab control switch. Items are ticked in advance for the agents this computer has.

## Setting up

**Set up selected** turns the chosen switches on at once and writes Codex's config.toml for you. The commands that must run in a terminal are joined into one line and typed into a new terminal without pressing Enter: one Enter from you runs them. **Later** closes the card. Either way it does not come back by itself; Settings, Extensions, **Open the list** shows it again.

Other first-run hints, such as the bubble under the + button and the Coordinator tour, wait until this card is answered.
