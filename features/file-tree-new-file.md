# New file in the file tree

Press the plus button in the file tree header, or right-click a folder, a file or empty space and choose New file. An input row appears in the target folder.

Type a name such as notes.txt, readme.md, data.json or paper.tex and press Enter. Esc or an empty name cancels. A right click on a folder creates the file inside it, and a right click on a file creates it beside it.

Ceteris refuses a name that already exists, so it never empties an existing file. New txt, json and md files open next to the terminal right away.

This works for local folders only. The tree for SSH servers stays read-only.
