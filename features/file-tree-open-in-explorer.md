# Open in File Explorer and delete from the file tree

Right-click a folder in the file tree and choose Open in File Explorer. The folder opens in the system file manager.

The same item appears when you right-click the file tree header, a pinned folder block, or the empty space below the rows. Those open the folder shown at the top of the tree, or the pinned folder.

Right-click a file and choose Show in File Explorer. The file manager opens its folder with the file selected. Ceteris never runs the file.

Right-click a file or folder and choose Delete to move it to the Recycle Bin. There is no confirm dialog, because you can restore the item from the Recycle Bin. Ceteris never erases files for good.

This works for local folders only. Folders on an SSH server live on another machine, so the tree leaves these items out for them.
