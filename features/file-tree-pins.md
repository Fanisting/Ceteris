# Pinned folders in the file tree

You can pin folders you visit often. Right-click a folder in the file tree, or the tree header, and choose Pin to top.

Pinned folders appear as small blocks under the header. Click a block to show that folder in the tree. Click it again, or change the session folder, to go back to the folder of your current terminal.

Pins work for remote folders too. A remote pin keeps its SSH profile and is browsed read-only. Pins are shared by all windows and follow a local folder when you rename it in the tree.
