# Folder blocks

The Folders header in the sidebar has a toggle between a list and blocks. Blocks show each folder as a small rounded pebble.

A pebble shows the folder name and one status dot for each terminal in it, up to five. Pebbles are as wide as their names and wrap like words.

Click a pebble to see that folder's terminals under a back row. Click the back row to return to all pebbles. The folder you are working in has a ring around it.

Menus, renaming, tags and drag and drop work the same in both layouts. Ceteris remembers your choice.
