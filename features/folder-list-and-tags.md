# One folder list with tags

Ceteris keeps one list of folders in the sidebar. Any folder where you open a terminal stays in the list, and you can rename it.

You can give a folder coloured tags. The tags show as dots next to the folder name. Click a dot to show only the folders with that tag. Right-click a dot to rename or recolour it.

You can select more than one tag to narrow the list further. Tags only organise the list. They never move or change your files.

Earlier versions had three categories: favourites, temporary and recent. These were replaced by this single list.
