# Formula images for Claude Code

With this extension, formulas written by Claude Code show as real typeset images in the terminal instead of raw LaTeX.

It is off by default. Turn it on in Settings under Extensions. New terminals then accept inline images. The same page shows how to install the small Claude Code plugin that renders each formula in your terminal colours.

Terminals you opened before the switch need to be restarted. On Windows the extension also changes the terminal backend, which is why it is an opt-in choice.

Related: [ADR-019](../docs/软件定义书.md) and [Formula rendering for Codex](formula-rendering-codex.md).
