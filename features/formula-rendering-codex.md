# Formula rendering for Codex

Codex writes formulas as plain text in dollar signs or backslash brackets. With this extension, Ceteris draws them as typeset math right where they appear.

It is off by default. Turn it on in Settings under Extensions. The page also has a button that adds one line to your Codex instructions, asking it to put each formula in inline code so Ceteris can find it.

The drawing happens in Ceteris itself, so it works with the text Codex already prints.
