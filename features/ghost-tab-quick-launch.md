# Ghost tab quick launch

The tab strip ends with a dashed tab, the ghost tab. It holds small icons for the agents you launch most, followed by the new tab button.

One click on an icon opens that agent in the selected folder. The new tab button still opens the full template list.

Choose which agents appear in Settings under Behavior, in the Quick launch section. By default these are Claude Code and Codex.

The first time you open a folder, a small bubble under the new tab button points this out. It goes away after you click "Got it" or use the icons once, in every window.
