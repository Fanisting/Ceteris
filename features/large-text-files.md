# Large text files

Text and JSON files larger than 2 MB open as read-only pages. Ceteris loads one page at a time and you move with a slider.

Because only one page is loaded, a file of several gigabytes opens at once. Log files are a good example.

Files under the limit open in the normal editor, see [Text file editing](text-file-editing.md).
