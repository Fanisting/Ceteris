# Live PDF preview

A PDF you open in the file panel updates when the file is rebuilt. The page, position and zoom stay where they were.

This works for local files and for PDFs on an SSH server. Write a paper on a remote machine, compile it there, and the preview follows each build.

Use the zoom buttons in the header, or Ctrl and the mouse wheel. If a refresh fails, the header says so, and one click tries again.

Related: [ADR-017](../docs/软件定义书.md) and [File viewer](file-viewer.md).
