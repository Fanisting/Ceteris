# Next prompt suggestions

When a coding agent finishes, Ceteris can suggest your next message to it. A model reads the end of the screen and proposes a short prompt.

The suggestion learns from you. Messages you repeat three or more times in Claude Code or Codex are sent along as examples, so your habits shape the guess.

You can choose any model from a list with prices, or type another name. OpenRouter is the default service. Click Connect OpenRouter in Settings under AI Assistant and sign in in your browser. The key is stored encrypted and is sent only to OpenRouter. You can also enter a different OpenAI-compatible address, including a local model.

The same page shows a daily cost chart, split by model, and a running total that you can reset.
