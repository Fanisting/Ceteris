# OnePage Markdown look

Markdown files open with a reading style taken from the OnePage theme for Obsidian. It looks like a page of paper.

Light themes get a warm white page and dark themes get a warm brown one. Headings, bold and italic text are coloured. Inline code appears in pills, tables have grids, and quotes get a floating vertical bar. Line spacing is a little tighter than before.

The style applies to every Markdown file you open in the file panel. Use the Edit button to change the text.
