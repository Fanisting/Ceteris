# PDF slides view

A PDF can be shown one page at a time, like a slide deck. This suits Beamer talks and decks exported from PowerPoint or Keynote.

Open a PDF from the file tree, then click **Slides** in its header. **Scroll** goes back to the usual continuous pages.

In Slides:

- The page fits the pane on a dark background. Zoom buttons hide because the whole page is always visible.
- Click the right half of the page for the next slide and the left half for the previous one. One wheel notch turns one page.
- The header shows the page number, for example 3 / 24, with previous and next buttons.
- A strip of thumbnails runs along the bottom. Click one to jump to that page.
- Text stays selectable, and links still open in the browser.

The view follows rebuilds: compile the deck again and it stays on the same slide. The choice stays while the window is open, so switching sessions and coming back keeps Slides. Another file opens in Scroll.

There are no keyboard shortcuts for turning pages, in line with the mouse first design.
