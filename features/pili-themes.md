# Pili themes

The Pili series adds 38 Material 3 themes. They use the 19 theme colours of the PiliPlus client: a default green, pink, and 17 Material colours. Each colour has a light and a dark version.

Ceteris builds the full palette from the seed colour with the same method as PiliPlus. Dark tabs use the tinted card colours of its dark mode.

Pick a Pili theme in Settings under Appearance, in the theme menu.
