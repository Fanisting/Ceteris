# Stable, beta and dev channels

You can run a stable, a beta and a dev build of Ceteris at the same time. Each keeps its own data, so testing a new build never touches your daily setup.

The title bar, taskbar and tray show which channel a window belongs to. Remote tmux sessions are separate too, so a test build cannot type into a real session.

Most people only use stable. The beta and dev builds are for trying new work before it is released. Beta and dev do not check for updates.
