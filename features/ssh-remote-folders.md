# SSH profiles and remote folders

You can save SSH servers as profiles in Settings under Remote. Ceteris reads your existing ssh config, so hosts you already use appear without retyping.

Add a folder on a server to the same sidebar list as your local folders. Its label shows the profile and the remote path. A tab opened there is a normal terminal connected to that server.

When you add a remote folder, you can browse the server's directories instead of typing the path. If the server cannot be reached, you can still type it.
