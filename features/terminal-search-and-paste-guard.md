# Terminal search and paste guard

Press Ctrl+F in a terminal to search its scrollback. The search box shows the match count and jumps between matches.

When you paste text with several lines, Ceteris asks you to confirm first. This stops a pasted script from running line by line before you have read it.

You can also drop a folder onto the terminal area. Ceteris opens a new tab in that folder.
