# Text file editing

You can edit txt, json, md, tex, sql and hive files right in the file panel and save them. There is no need to open another editor for a quick change.

For txt, json, tex, sql and hive, a click opens a text editor. For Markdown, the file opens as a rendered page first. Use the Edit button in the header to switch to the editor and the Preview button to switch back. The preview shows unsaved changes too.

If another program changes the file while you edit, Ceteris does not overwrite it and tells you about the conflict. Unsaved text survives a lost connection and a closed window.

This is a light editor. It is not meant to replace your code editor.

Related: [ADR-016 and ADR-028](../docs/软件定义书.md).
