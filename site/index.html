Why it exists

If you have ever done one of these, Ceteris is for you.

smart_toyRun five AI coding agents in five projects and forgotten which one was waiting for your input.
closeClosed a terminal window by accident and killed a two-hour build, a long test run, or an agent mid-task.
keyboardTyped a deeply nested cd path for the third time today.
dnsJumped between remote servers and wished SSH sessions were organised by path, not by a pile of tabs.
How it works

Four ideas, and everything else follows.

Ceteris is short for ceteris paribus, all else equal. Change where the window is, and nothing else changes.

shield

Sessions survive window closure

Close every window. Sessions keep running in the background. Reopen any window and they are all still there, with their scrollback.

folder_open

Paths are first class

Keep working directories in one list and filter it by colour tag. Sessions are grouped by where they live, not by which profile spawned them.

mouse

Mouse first

No shortcuts to memorise and no cd to type. Click a folder in the sidebar, click + in the tab strip. That is the whole workflow.

grid_view

All windows are equal

There is no main window. Open as many as you want on any folder, close any of them, and the app keeps running in the tray or Dock.

Built for AI coding agents

See what every agent is doing without switching tabs.

Ceteris began from the frustration of running several Claude Code and Codex sessions at once and losing track of which one was idle, which one was waiting, and which one had been killed by closing the wrong window.

waves

Agent-aware tabs

The tab underline changes shape while Claude Code or Codex generates, waits or runs a command. A stalled approval prompt breathes in a warning colour until you answer.

filter_alt

Running and waiting filters

Two sidebar filters show only the terminals that are running, or only the agents waiting for you. A finished agent leaves a dot on its tab until you look.

hub

Coordinator tabs

Mark a tab as coordinator and it stays above the strip in every folder. A Claude Code coordinator can open, read, prompt and close the other tabs in its folder.

rocket_launch

Launch templates

Claude Code, Codex, OpenCode, Gemini CLI, GitHub Copilot, Cursor and Aider are built in, plus your own commands. Right-click + for a quick-launch ring.

functions

Formulas rendered inline

Formulas that Claude Code and Codex print show as rendered images in the terminal, so a derivation reads the way it was meant to.

draft

Files beside the terminal

Open a file next to a terminal instead of over it. Edit text, JSON, Markdown and TeX, and page through multi-gigabyte logs instantly.

picture_as_pdf

PDFs that follow the file

A PDF in the file panel, local or on an SSH server, reloads when it is rebuilt and keeps its page and zoom. Made for the LaTeX edit and compile loop.

cloud

Remote paths and tmux

Bookmark remote working directories beside local ones. Start or attach to tmux on a host with one click, and fall back to the shell when tmux exits.

cast

Ceteris Link

Open the tabs running on another Windows machine, live. Same sessions, same scrollback, same agents, end-to-end encrypted with a token that never travels.

palette

Themes

Dozens of Material Design 3 themes, including live ones built from a seed colour or your Windows accent. Pearl, Beamer and your own CSS themes too.

Try it in a minute

That's it. That's the product.

Open a few sessions

Add two or three folders and start a shell or an agent in each.

Close the window

Click ×. Ceteris stays in the system tray on Windows, or in the Dock on macOS.

Open a new one

Click the tray icon. A fresh window opens, and every session is still running.

Carry on

Your build is still building and your agent is still working. Nothing was lost.
